Vice Frame is an offline web app that turns your photo and a caption into GTA-style multi-panel poster cover art — pick a layout (Vice Split, Triptych, Sunset Grid, Hero Strip), crop and position up to 3 photos, choose a Sunset / Neon Nights / Noir grade and a lettering style, then export a PNG in 1080x1080, 1080x1350 or 1920x1080. No photo ever leaves your machine; the app makes no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Or serve the app/ folder with any static HTTP server and open app/index.html.
